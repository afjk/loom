Clamp and map - 範囲リマップで動的に挙動を変える

時間経過とともに sine の周波数が 0.1Hz から 5Hz へ徐々に上がる。map ノードで時間を周波数にリマップし、clamp パラメータで範囲外を抑えている。map は TouchDesigner の Math CHOP の Range や Houdini の fit() 関数に相当する。

グラフ: clock → map[t: 0~30s → freq: 0.1~5Hz] → sine → map[out: -1~1 → width: 50~750px] → bar.style.width
時刻: 0.0s | 周波数: 0.1 Hz
