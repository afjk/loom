# Loomlet 用語集

この用語集は、Loomlet のドキュメント、ランタイム、ツール群で使う共通用語を定義します。

## 基本用語

- **Loomlet**: インタラクティブなシーンのための、小さなリアクティブDSLおよびノードグラフツールキット。
- **DSL**: 人間やAIが記述する `.loom` ソース言語。
- **Source AST**: DSLソースから得られる、構文を保持する構造。安全な編集や整形のために使う。
- **Graph AST**: ノード、ポート、エッジ、paramsを持つ、エディタ向けのグラフ構造。
- **Runtime Graph**: ランタイムが実行するための最小限のグラフ表現。
- **Target Graph**: Web、Scene Sync、Unityなど、特定のホストや統合先に合わせて変換されたグラフ表現。
- **Graph**: ノードとエッジで振る舞いを表す、接続されたデータフロー表現。
- **Node**: 値の計算、明示的な状態の保持、入力の読み取り、副作用の発行を行うグラフ要素。
- **Port**: ノード上の型付きの接続端子。
- **Input**: 接続可能なノード入力スロット。別ノードの出力、ローカル定数、ノードのデフォルト値を受け取れる。
- **Output**: 値またはイベントを下流の入力へ出力するノードポート。
- **Param**: ノードの静的な設定値。基本的にはエッジで接続しない。
- **Value**: behaviorポートを流れるデータ、またはparams/defaultsとして使われるデータ。
- **Behavior**: 時間に沿って現在値を持つ信号。`behavior` ポート上で各tickごとに評価される。正式な意味論は `docs/SPEC.md` を参照。
- **Event**: ある評価tick内で0個以上のpayloadを運ぶ離散的な信号。`event` ポート上で扱われる。正式な意味論は `docs/SPEC.md` を参照。
- **Behavior Graph**: オブジェクトやシーンの振る舞いを記述するグラフ。`behavior` ポート種別とは別の概念。正式な意味論は `docs/SPEC.md` を参照。
- **Port kind**: ポートが運ぶ信号のカテゴリ。現在は `behavior` または `event`。payloadの型とは独立している。正式な意味論は `docs/SPEC.md` を参照。
- **Type**: valueまたはportに関連付けられるデータ型。
- **Adapter**: Loomletランタイムの出力を、ホストやランタイムのAPIへ対応付ける統合レイヤー。
- **Package / Library**: Loomletで再利用できるノード、ヘルパー、メタデータのまとまり。
- **Capability**: ランタイムやターゲット環境で利用可能な機能セットの宣言。

## behavior port と Behavior Graph

- **behavior port** は、各tickごとに評価される現在値の信号を意味します。
- **Behavior Graph** は、オブジェクトやシーンの振る舞いを記述するグラフを意味します。
- これらは関連していますが、同じ概念ではありません。
- `behavior` / `event` の正式な意味論と接続ルールは `docs/SPEC.md` で定義します。

## Input と Param

- **Input** は接続可能で、次の優先順位で値を解決できます。
  1. 上流ノードの出力
  2. ローカル定数
  3. ノードのデフォルト値
- **Param** はノードの静的な設定値で、基本的にはエッジで接続しません。

## ラウンドトリップとテスト関連の用語

- **Canonical DSL**: グラフから生成される `.loom` テキスト。parse可能で決定的であることを目指すが、元ソースのコメント、書式、pipe構文、引数の書き方を必ず保持するものではない。
- **Round-trip**: ある表現から別の表現へ変換し、再び戻すこと。例として、DSLからgraph、canonical DSL、graphへ戻す流れや、graphからeditor model、graphへ戻す流れがある。ラウンドトリップごとに安定化の目標は異なる。
- **Golden test**: 現在の出力を、期待されるfixtureやsnapshotと比較するテスト。安定させる意図がある出力にだけ慎重に適用する。
- **Semantic graph equivalence**: 生のJSONが完全一致するかではなく、グラフの意味が等価かどうかを比較すること。意図的にテスト対象にしない限り、視覚メタデータ、ノードレイアウト、timestamp、生成された実装詳細は意味的等価性に影響しない。

## 将来の値カテゴリ

Loomletの用語とメタデータは、将来的に次の値カテゴリと互換性を保つべきです。

- `number`
- `string`
- `boolean`
- `vec2`
- `vec3`
- `vec4`
- `record`
- `list`
